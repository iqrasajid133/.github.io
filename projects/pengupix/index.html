Case study

PenguPix: image tools that stay on your device

PenguPix is a free online toolkit of 39 image tools that run in the browser. It is one of my own web projects, designed and built from scratch.

Visit PenguPix ↗All projects

Overview

Many online image tools ask visitors to upload files to a server, create an account or wade through clutter. PenguPix takes the opposite approach: a friendly, focused toolkit where the tools run in the browser, according to the site, files never leave your device.

The site is built around making everyday image jobs, like resizing a photo to a target size or converting a format, simple and quick, with a friendly brand identity.

Tagline: “Your Images. Penguin-simple.”

pengupix.online · Designed and built by Iqra Sajid

Features

What it does

Resize and compress

Image resizer and compressor, plus presets to resize to 50KB, 100KB or 200KB, an image dimensions tool and an aspect ratio calculator.

Crop, rotate and convert

Cropper, rotate and flip, JPG, PNG and WebP conversion, image to PDF, PDF to image and Base64 conversion.

Effects and editing

Blur, pixelate, filters, duotone, borders, rounded corners, shadows, text on image, watermark and background colour.

Collages

Collage maker and photo grid.

Metadata and analysis

EXIF viewer, metadata remover and DPI checker.

Colour and SVG

Colour picker, palette generator, SVG to PNG, SVG optimiser and SVG resizer.

Creator tools

Favicon generator, QR code maker and Open Graph image maker.

My role

What I did

  • Brand and interface design, including the penguin-themed identity and the tagline.
  • Web development of the toolkit, where the tools run in the visitor's browser.

The site states that it needs JavaScript to run its image tools, because processing happens in the browser.

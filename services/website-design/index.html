Service

Website design and development built to be found and used

A good website is clear, fast and easy to use on any device. I design and build responsive websites and landing pages, with the fundamentals that help search engines understand them.

What’s included

Business and portfolio websites

Multi-page sites with a clear structure, strong visual identity and straightforward navigation.

Landing pages

Focused single-page experiences designed around one goal, such as an enquiry, a sign-up or a product.

Web tools and apps

Interactive browser-based tools, like the ones in my own projects PenguPix and SocialSEO IQ.

SEO and performance foundations

Semantic HTML, metadata, structured data, sitemaps, optimised images and mobile-friendly layouts.

Process

How I work

  1. Plan

    We define the goal, audience, pages and content. Structure comes before visuals.

  2. Design

    I design the look and interaction, keeping layouts accessible and readable on every screen size.

  3. Build

    The site is built with clean, semantic code and tested across devices and browsers.

  4. Launch

    Metadata, sitemap and redirects are set up before launch so the site is ready to be crawled.

FAQ

Frequently asked questions

Do you build landing pages as well as full websites?

Yes. A landing page is one of the most common projects: a single focused page built around a single call to action.

Will the website work on mobile phones?

Yes. Every site I build is designed mobile-first and tested on phone, tablet and desktop sizes.

Do you handle SEO?

I build the technical foundations: titles, descriptions, headings, structured data, sitemap and fast loading. No one can promise rankings, but a well-built site gives search engines what they need.

What do I need to get started?

A short description of your business, your goal for the site, and any existing logo, text or images. We can work out the rest together.

Have a project in mind?

Tell me about your brand, campaign or website and I will reply personally.
